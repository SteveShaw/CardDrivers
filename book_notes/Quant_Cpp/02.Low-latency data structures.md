# Low-latency data structures

Typical problems include implementing:

- SPSC ring buffer
- MPSC queue
- lock-free queue
- fixed-size object pool
- slab allocator
- intrusive linked list
- flat hash table
- timer queue
- price-level lookup structure
- sequence-number/reorder buffer

For example:

* Implement a fixed-capacity SPSC queue without locks.

You should immediately be thinking about something like:

```cpp
template<typename T, size_t N>
class SPSCQueue {
    alignas(64) std::atomic<size_t> head_{0};
    alignas(64) std::atomic<size_t> tail_{0};

    std::array<T, N> buffer_;
};
```

Then expect follow-ups:

- Why separate `head` and `tail`?
- What is false sharing?
- Which memory ordering do you need?
- Do you actually need `seq_cst`?
- What happens when counters wrap?
- What if `T` isn't default constructible?
- How would you benchmark it?
