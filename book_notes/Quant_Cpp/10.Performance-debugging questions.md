# Performance-debugging questions

You may get code like:

```cpp
std::vector<Order*> orders;

for (auto* o : orders)
    process(*o);
```

and be asked:

* Why could this be slow?

Possible issues include pointer chasing, cache misses, allocation fragmentation and branch behavior.

or 

```cpp
std::map<int, Order> orders;
```

* We process 20 million market-data messages/sec. How would you improve this?

A strong discussion might cover contiguous memory, flat/open-addressing hash tables, preallocation, integer price indices, object pools, avoiding allocation on the hot path, and profiling before optimizing.
