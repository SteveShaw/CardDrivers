# 滑动窗口算法经典习题

## 1658. Minimum Operations to Reduce X to Zero

You are given an integer array `nums` and an integer `x`. In one operation, you can either remove the leftmost or the rightmost element from the array `nums` and subtract its value from `x`. Note that this **modifies** the array for future operations.

Return *the **minimum number** of operations to reduce* `x` *to **exactly*** `0` *if it is possible**, otherwise, return* `-1`.

**Example 1:**

**Input:** nums = [1,1,4,2,3], x = 5
**Output:** 2
**Explanation:** The optimal solution is to remove the last two elements to reduce x to zero.

**Example 2:**

**Input:** nums = [5,6,7,8,9], x = 4
**Output:** -1

**Example 3:**

**Input:** nums = [3,2,20,1,1,3], x = 10
**Output:** 5
**Explanation:** The optimal solution is to remove the last three elements and the first two elements (5 operations in total) to reduce x to zero.

#### 基本思路

题目要求从边缘删除掉和为 `x` 的元素，那剩下来的是 `nums` 中的一个子数组。尽可能少地从边缘删除元素说明剩下来的这个子数组大小尽可能的大。

**所以，这道题等价于寻找 `nums` 中元素和为 `sum(nums) - x` 的最长子数组**。

基于滑动窗口，需要搞清楚以下几个问题：

1、什么时候应该扩大窗口？

2、什么时候应该缩小窗口？

3、什么时候得到一个合法的答案？

针对本题，以上三个问题的答案是：

1、当窗口内元素之和小于目标和 `target` 时，扩大窗口，让窗口内元素和增加。

2、当窗口内元素之和大于目标和 `target` 时，缩小窗口，让窗口内元素和减小。

3、当窗口内元素之和等于目标和 `target` 时，找到一个符合条件的子数组，我们想找的是最长的子数组长度。

**Note**: 本题可以用滑动窗口是因为 `nums` 都是正数，这就保证了加入滑动窗口，`sum`一定变大，而离开窗口，`sum`一定变小。

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    int minOperations(vector<int>& nums, int x) {
        int n = nums.size(), sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums[i];
        }
        // 滑动窗口需要寻找的子数组目标和
        int target = sum - x;

        int left = 0, right = 0;
        // 记录窗口内所有元素和
        int windowSum = 0;
        // 记录目标子数组的最大长度
        int maxLen = INT_MIN;
        // 开始执行滑动窗口框架
        while (right < nums.size()) {
            // 扩大窗口
            windowSum += nums[right];
            right++;

            while (windowSum > target && left < right) {
                // 缩小窗口
                windowSum -= nums[left];
                left++;
            }
            // 寻找目标子数组
            if (windowSum == target) {
                maxLen = max(maxLen, right - left);
            }
        }
        // 目标子数组的最大长度可以推导出需要删除的字符数量
        return maxLen == INT_MIN ? -1 : n - maxLen;
    }
};
```

## 713. Subarray Product Less Than K

You are given an array of integers `nums` and an integer `k`.

Return the number of contiguous subarrays where the **product** of all the elements in the **subarray** is **strictly less** than `k`.

**Example 1:**

**Input:** nums = [10,5,2,6], k = 100
**Output:** 8
**Explanation:** The 8 subarrays that have product less than 100 are:
[10], [5], [2], [6], [10, 5], [5, 2], [2, 6], [5, 2, 6]
Note that [10, 5, 2] is not included as the product of 100 is not strictly less than k.

**Example 2:**

**Input:** nums = [1,2,3], k = 0
**Output:** 0

**Constraints:**

```cpp
1) 1 <= nums.length <= 3 * 10^4
2) 1 <= nums[i] <= 1000
3) 0 <= k <= 10^6
```

#### 基本思路

使用滑动窗口算法：

1、移动右边界加入一个元素，枚举下一个子数组的右端点。

2、当窗口元素之积大于等于 `k` 时，移动左边界缩小窗口，直到乘积小于 `k`。

3、此时窗口内所有以当前右端点结尾的子数组都是合法的。代码中 `right` 已经右移，窗口为 `[left, right)`，因此新增 `right - left` 个答案；只统计这个右端点对应的子数组，就不会重复计数。

注意：当 `k <= 1` 时，正整数的乘积不可能小于 `k`，直接返回 0。其余情况下，之所以可以用滑动窗口，关键是 `nums` 中的元素都是正整数：加入元素后乘积不会减小，移出元素后乘积不会增大。元素为 1 时，乘积保持不变。

如果存在负数的话就没有这个性质了，也就不能确定什么时候扩大和缩小窗口，而应该使用`prefix sum` + `hash table`的算法，

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        int left = 0, right = 0;
        // 滑动窗口，初始化为乘法单位元
        int windowProduct = 1;
        // 记录符合条件的子数组个数
        int count = 0;

        while (right < nums.size()) {
            // 扩大窗口，并更新窗口数据
            windowProduct *= nums[right];
            right++;

            while (left < right && windowProduct >= k) {
                // 缩小窗口，并更新窗口数据
                windowProduct /= nums[left];
                left++;
            }
            // 现在必然是一个合法的窗口，但注意思考这个窗口中的子数组个数怎么计算：
            // 比方说 left = 1, right = 4 划定了 [1, 2, 3] 这个窗口（right 是开区间）
            // 但不止 [left..right] 是合法的子数组，[left+1..right], [left+2..right] 等都是合法子数组
            // 所以我们需要把 [3], [2,3], [1,2,3] 这 right - left 个子数组都加上
            count += right - left;
        }

        return count;
    }
};
```

#### 基本思路

基于`sliding window`，将`window`中的所有数字替换成 1，计算`window`可以达到的最大长度。

1、当可替换次数大于等于 0 时，扩大`window`，让进入`window`的 0 都变成 1，使得连续的 1 的长度尽可能大。

2、当可替换次数小于 0 时，缩小`window`。

3、只要可替换次数大于等于 0，`window`中的元素都会被替换成 1，也就是连续为 1 的子数组，计算最大`window`长度。

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int left = 0, right = 0;
        // 记录窗口中 1 的出现次数
        int windowOneCount = 0;
        // 记录结果长度
        int res = 0;

        // 开始滑动窗口模板
        while (right < nums.size()) {
            // 扩大窗口
            if (nums[right] == 1) {
                windowOneCount++;
            }
            right++;

            while (right - left - windowOneCount > k) {
                // 当窗口中需要替换的 0 的数量大于 k，缩小窗口
                if (nums[left] == 1) {
                    windowOneCount--;
                }
                left++;
            }
            // 此时一定是一个合法的窗口，求最大窗口长度
            res = max(res, right - left);
        }
        return res;
    }
};
```

## 424. Longest Repeating Character Replacement

You are given a string `s` and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times.

Return *the length of the longest substring containing the same letter you can get after performing the above operations*.

**Example 1:**

**Input:** `s = "ABAB"`, `k = 2`
**Output:** 4
**Explanation:** Replace the two `'A'`s with two `'B'`s or vice versa.

**Example 2:**

**Input:** `s = "AABABBA"`, `k = 1`
**Output:** 4
**Explanation:** Replace the one `'A'` in the middle with `'B'` and form "AABBBBA".
The substring `"BBBB"` has the longest repeating letters, which is 4.
There may exists other ways to achieve this answer too.

**Constraints:**

```java
1) 1 <= s.length <= 10^5
2) s consists of only uppercase English letters.
3) 0 <= k <= s.length
```

#### 基本思路

Use a **sliding window**: a section of the string that we expand or shrink as we move through it.

For any window

```
changes needed = window length − count of its most common letter
```

For example, `"AABA"` has length `4`, and `A` appears `3` times. We need just `4 − 3 = 1` change to make every letter `A`.

```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] counts = new int[26];
        int left = 0;
        int longest = 0;

        for (int right = 0; right < s.length(); right++) {
            counts[s.charAt(right) - 'A']++;

            // Shrink the window until it needs at most k changes.
            while ((right - left + 1) - maxCount(counts) > k) {
                counts[s.charAt(left) - 'A']--;
                left++;
            }

            longest = Math.max(longest, right - left + 1);
        }

        return longest;
    }

    private int maxCount(int[] counts) {
        int largest = 0;

        for (int count : counts) {
            largest = Math.max(largest, count);
        }

        return largest;
    }
}
```

## 219. Contains Duplicate II

Given an integer array `nums` and an integer `k`, return `true` *if there are two **distinct indices*** `i` *and* `j` *in the array such that* `nums[i] == nums[j]` *and* `abs(i - j) <= k`.

**Example 1:**

**Input:** nums = [1,2,3,1], k = 3
**Output:** true

**Example 2:**

**Input:** nums = [1,0,1,1], k = 1
**Output:** true

**Example 3:**

**Input:** nums = [1,2,3,1,2,3], k = 2
**Output:** false

**Constraints:**

```java
1) 1 <= nums.length <= 10^5
2) -10^9 <= nums[i] <= 10^9
3) 0 <= k <= 10^5
```

#### Solution

In the sliding window, if the window size is larger than `k`, shrink the window.
Anytime a duplicate number is found, just return `true`

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        int left = 0, right = 0;
        unordered_set<int> window;
        // 滑动窗口算法框架，维护一个大小为 k 的窗口
        while (right < nums.size()) {
            // 扩大窗口
            if (window.find(nums[right]) != window.end()) {
                return true;
            }
            window.insert(nums[right]);
            right++;

            //sliding window is [left, right)
            //so the window size is right - left
            if (right - left > k) {
                // 当窗口的大小大于 k 时，缩小窗口
                window.erase(nums[left]);
                left++;
            }
        }
        return false;
    }
};
```

## 209. Minimum Size Subarray Sum

Given an array of positive integers `nums` and a positive integer `target`, return *the **minimal length** of a* *subarray* *whose sum is greater than or equal to* `target`. If there is no such subarray, return `0` instead.

**Example 1:**

**Input:** `target = 7`, `nums = [2,3,1,2,4,3]`
**Output:** `2`
**Explanation:** `The subarray [4,3] has the minimal length under the problem constraint`.

**Example 2:**

**Input:** `target = 4`, `nums = [1,4,4]`
**Output:** `1`

**Example 3:**

**Input:** `target = 11`, `nums = [1,1,1,1,1,1,1,1]`
**Output:** `0`



**Constraints**:

* `1 <= target <= 10^9`

* `1 <= nums.length <= 10^5`

* `1 <= nums[i] <= 10^4`

#### Solution

`Sliding window` will shrink when the `sum` in the window is larger or equal to the `target`

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {

       int sliding_window_sum {};
       optional<ssize_t> min_size {};

       for(ssize_t left = 0,right = 0; right < ssize(nums); )
       {
          sliding_window_sum += nums[right];
          ++right;

          while(sliding_window_sum >= target && left < right)
          {
            if(!min_size || min_size.value() > right - left)
            {
                min_size = right - left;
            }
            sliding_window_sum -= nums[left];
            ++left;
          }
       } 

       return min_size.has_value() ? min_size.value() : 0;
    }
};
```
