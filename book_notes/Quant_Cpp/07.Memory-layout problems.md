# Memory-layout problems

These are disproportionately common in C++ trading interviews.

Example:

```cpp
struct A {
    char a;
    int b;
    char c;
    double d;
};
```

Questions:

* What is `sizeof(A)`?

* Where is padding inserted?

* How could you reduce the size?

Then they may move into:

```cpp
struct Order {
    uint64_t id;
    double price;
    uint32_t qty;
    char side;
};
```

and ask how you would organize millions of orders.

That introduces:

```textile
Array of Structures

Order Order Order Order
```

versus:

```textile
Structure of Arrays

ids:    [...]
prices: [...]
qty:    [...]
sides:  [...]
```

Expect questions about cache lines, locality, prefetching, alignment, and SIMD.
