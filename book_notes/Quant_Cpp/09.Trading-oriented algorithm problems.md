# Trading-oriented algorithm problems

These bridge algorithms and actual trading concepts.

**VWAP**

Given

```cpp
struct Trade {
    double price;
    int quantity;
};
```

calculate:

$$
\frac{\sum p_iq_i}{\sum qi}
$$

Then support streaming updates in $O(1)$.

**Rolling statistics**

Maintain the last `N` prices and return:

```textile
mean
variance
standard deviation
min
max
```

Expect discussion of numerical stability and $O(1)$ updates.

**Position/P&L**

Given executions:

```textile
BUY  100 @ 50
BUY  200 @ 51
SELL 150 @ 52
```

calculate:

```textile
position
average price
realized P&L
unrealized P&L
```

This is a very realistic interview problem because edge cases quickly appear.
