# Atomics and memory-ordering problems

Higher-end C++ trading interviews frequently test this.

You may be given:

```cpp
int data = 0;
std::atomic<bool> ready = false;

// thread 1
data = 42;
ready.store(true);

// thread 2
if (ready.load())
    std::cout << data;
```

Questions:

* Is this safe?

* Which memory orders should be used?

You should understand the release/acquire relationship:

```cpp
ready.store(true, std::memory_order_release);

if (ready.load(std::memory_order_acquire))
    std::cout << data;
```
