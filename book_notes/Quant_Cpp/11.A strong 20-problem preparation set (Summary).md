# A strong 20-problem preparation set

If I were preparing specifically for a **C++ quant developer interview**, I'd make sure I could solve these from scratch:

1. Implement `Vector<T>`
2. Implement `UniquePtr<T>`
3. Implement simplified `SharedPtr<T>`
4. Implement simplified `std::function`
5. Implement LRU cache
6. Implement object pool
7. Implement SPSC ring buffer
8. Thread-safe producer/consumer queue
9. Deadlock-free account transfer
10. Explain/fix an atomic memory-ordering bug
11. Build a limit order book
12. Maintain best bid/ask
13. Market-data sequence/reorder buffer
14. Streaming VWAP
15. Streaming mean/variance
16. Position + realized/unrealized P&L
17. Sliding-window maximum
18. Median from streaming data
19. Top-K / heap problem
20. Diagnose and optimize a cache-unfriendly piece of C++.

For a **quant dev rather than quant researcher** position, I'd put the most preparation time into **#1–13**. They expose whether you actually understand C++ systems programming rather than just know algorithm patterns.
